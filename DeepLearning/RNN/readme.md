## Name Gender Classification (RNN)

### Architecture: 
Recurrent Neural Network (RNN)

### Objective: 
Predict gender based on a person's name

### Dataset: 
NLTK Names Corpus

### Highlights:

- Character-level tokenization

- Used SimpleRNN for sequence modeling

- Compared with Logistic Regression to show RNN advantages

- Deployed as a Streamlit app

### Tools:

`TensorFlow`, `Keras`, `NLTK`, `Scikit-learn`, `Streamlit`
