## Sign Language Detection (CNN)

### Architecture: 
Convolutional Neural Network (CNN)

### Objective: 
Classify ASL hand gestures (A–Z) using image data.

### Dataset: 
Sign Language MNIST - Kaggle

### Highlights:

- Built a CNN with Conv2D, MaxPooling, Flatten, Dense layers

- Applied data augmentation with ImageDataGenerator

- Trained on grayscale 28x28 images

- Saved the model and predicted static input images

### Tools:

`TensorFlow`, `Keras`, `OpenCV`, `Streamlit`, `Matplotlib`
