## Stock Price Prediction (LSTM)
### Architecture: 
Long Short-Term Memory (LSTM)
### Objective: 
Forecast stock closing prices using past 60-day values
### Dataset: 
yfinance
### Highlights:
- Applied MinMaxScaler for normalization
- Used sliding window technique for time-series data
- Built a stacked LSTM model
- Plotted predicted vs actual prices
### Tools:
`TensorFlow`, `Keras`, `Pandas`, `Matplotlib`, `yfinance`
