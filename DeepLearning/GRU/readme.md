## Emotion Detection from Text (GRU)

### Architecture: 
Gated Recurrent Unit (GRU)

### Objective: 
Detect emotion (e.g., happy, sad, anger) from text
### Dataset: 
Emotion Dataset for NLP - Kaggle

### Highlights:

- Text preprocessing: tokenization, padding

- Multi-class classification using GRU

- Encoded labels with LabelEncoder

- Deployed as a real-time Streamlit web app

### Tools:

`TensorFlow`, `Keras`, `Scikit-learn`, `Streamlit`, `Pandas`
